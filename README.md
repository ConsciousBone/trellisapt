# Trellis APT repo

This repo contains useful jailbreak tweaks for use with Trellis.

## Tweaks available

- Vine ++ (`debs/vpp.deb`)
  - Adds additional features to the Vine app, such as downloading Vines and disabling auto-play.

- VineDownloader (`debs/down.deb`)
  - Allows you to download Vines to your camera roll. That's it. There's nothing more.

- vinesslpinningdisabler (`debs/ssldis.deb`)
  - Removes SSL pinning from the Vine app, which can fix connection issues with the Trellis server when using versions of Vine that require this.
