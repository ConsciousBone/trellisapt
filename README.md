# Trellis APT repo
This repo contains useful jailbreak tweaks for use with Trellis.  

# Tweaks available
- Vine ++ (`debs/vpp.deb`)
  - This adds additional features to the Vine app, such as downloading Vines and disabling auto-play.
- VineDownloader (`debs/down.deb`)
  - This allows you to download Vines to your camera roll. That's it. There's nothing more.
- vinesslpinningdisabler (`debs/ssldis.deb`)
  - This removes SSL pinning from the Vine app, which can fix connection issues to the Trellis server when using versions of Vine that require this.
